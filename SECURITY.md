# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private reporting instead:
**Security tab → Report a vulnerability** on this repository.

Include what you found, steps to reproduce, and the impact. You can expect an initial response within a few days.

## Scope

Of particular interest: anything that could make Juncle delete files outside its intended locations, escape the user-profile restriction on large-file deletion, or run unintended code.
