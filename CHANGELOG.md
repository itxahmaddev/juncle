# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-16

### Added
- Junk Cleaner for temp files, browser caches, thumbnails, crash dumps, Windows Update cache and the Recycle Bin
- Memory Booster with live RAM usage and top programs
- Disk Space overview and large-file finder
- Startup manager (reversible)
- Light and dark themes
