# AGENTS.md

Guidance for AI coding assistants working in this repository.

## What this is

Juncle is a free, open source junk cleaner and system booster for Windows, built with Tauri 2 (Rust backend) and a dependency-free web frontend (plain HTML, CSS and JS in `src/`, no bundler).

## Commands

**Prerequisites:** [Rust](https://rustup.rs/) (stable, MSVC), [Node.js](https://nodejs.org/) 18+, Visual Studio Build Tools with the C++ workload.

```bash
npm install            # install the Tauri CLI and prettier
npm run dev            # run the app in development
npm run build          # build the installer (src-tauri/target/release/bundle/nsis)
```

**Before committing:**

```bash
npm run lint           # JavaScript syntax check
npm run format         # prettier + cargo fmt
npm run format:check   # verify formatting (CI runs this)
cargo clippy --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml
```

## Architecture

- `src-tauri/src/lib.rs`: all Tauri commands. `categories()` defines what counts as junk; `scan_junk` / `clean_junk` walk those folders; `memory_info` / `optimize_memory` use `sysinfo` and Win32 `EmptyWorkingSet`; `disk_info`, `find_large_files`, `delete_files`; `list_startup` / `set_startup` use the registry.
- `src/index.html`, `src/style.css`, `src/app.js`: the UI. Every page has the same layout: title, scrollable content, one action bar at the bottom with the primary action on the right.
- `.github/workflows/`: `build.yml` is the reusable build; `main-build`, `build-test`, `pr-test-build` and `release` call it. `code-quality` and `test` run checks.

## Rules that matter

- **This app deletes files. Be conservative.** Only add junk locations that are safe to delete and regenerated by their owner. Never delete user documents, never force-delete files in use, always keep the confirmation dialog before destructive actions.
- `delete_files` must keep refusing anything that is not a regular file inside the user's profile.
- Disabling a startup program must stay reversible (it moves the registry value to `HKCU\Software\Juncle\DisabledStartup`).
- Keep the frontend dependency-free.
- Do not start or run the cleaner against a real machine to "test" a change unless the user explicitly asks; prefer `cargo check`, `cargo test` and a mocked UI preview.
- AI-assisted pull requests must be opened by a human with a human-written description. See `.github/PULL_REQUEST_TEMPLATE.md`.
